Rank by how much the developer's attention unblocks valuable work:

1. Complex work and new features first: plan problems, design decisions and blockers on substantial feature work.
2. Then bugs and failures the agent cannot resolve itself (CI failures, broken environments), weighted by impact.
3. Then finished work that is ready for review.
4. Lower: updates, research findings and informational questions.

Within the same level, a question that blocks more work ranks higher, and one that has waited longer breaks ties.
